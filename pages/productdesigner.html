Compra Gamer

Como proyecto académico rediseñé Compra Gamer, un e-commerce especializado en hardware y accesorios para gaming.

Metodologías aplicadas

  • Test de usabilidad para identificar puntos de mejora en la experiencia actual.
  • Atomic Design para mantener la consistencia entre componentes.
  • Prototipos interactivos en Figma para visualizar la propuesta final.

Resultado

El diseño final mejora la navegación, simplifica el proceso de compra y apunta a una mayor satisfacción del usuario.

Este portfolio

Diseñé y estructuré este sitio para que refleje mi enfoque profesional, aplicando principios de usabilidad y diseño centrado en el usuario.

  • Prototipado: wireframes y prototipos de alta fidelidad en Figma.
  • Pruebas: test con usuarios para validar decisiones y ajustar elementos clave según el feedback.
