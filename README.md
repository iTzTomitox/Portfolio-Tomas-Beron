## Sobre este sitio

Portfolio estático publicado con GitHub Pages: HTML, Sass y JavaScript sin frameworks.

```
index.html              Portada
pages/                  Trabajos, áreas (UX/UI, audiovisual, web, gráfico) y contacto
404.html                Página de error
scss/                   Estilos fuente (tokens, base, componentes y páginas)
css/styles.css          CSS compilado (es el que carga el sitio)
script/main.js          Tema claro/oscuro, menú móvil, animaciones y video diferido
script/formulario.js    Envío del formulario de contacto con EmailJS
assets/img/             Imágenes optimizadas en WebP (varios tamaños)
assets/icons/sprite.svg Íconos de herramientas y redes
sitemap.xml, robots.txt SEO
```

### Editar estilos

```bash
npm install
npm run watch   # recompila css/styles.css mientras editás scss/
npm run build   # versión final minificada
```

### Agregar una imagen

Exportala en WebP (ancho de 800 px y 1600 px, por ejemplo `mi-proyecto-800.webp` y `mi-proyecto-1600.webp`) en `assets/img/` y usala con `srcset`, `width`, `height`, `alt` y `loading="lazy"`, como el resto de las imágenes.

### Al publicar una página nueva

Agregala a `sitemap.xml` y dale su propio `<title>`, `meta description`, `canonical` y etiquetas Open Graph.
